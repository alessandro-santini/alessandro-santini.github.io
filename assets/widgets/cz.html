In the digital mode the qubit lives in two hyperfine ground states, g = 0 and h = 1, which do not interact. To entangle two atoms the protocol borrows the Rydberg state for a moment: a π-pulse takes the control from g to r, a 2π-pulse on the target would take it g → r → g with a phase −1, but is blocked when the control sits in r, and a last π-pulse brings the control back. Each input state picks up a phase −1 unless both atoms are in h, which is the CZ gate up to a global phase. The blockade is never perfect: with a finite shift B = C6/(ħR6) the 2π-pulse on the target is merely detuned by B, the state |rg⟩ picks up a stray phase and a little population leaks to |rr⟩. Both errors scale as Ω/B and the gate error as (Ω/B)2: move the atoms closer and it falls by six orders of magnitude over a few micrometres. A weaker drive helps the blockade and a stronger one makes the gate shorter, which is the trade-off of the design.
